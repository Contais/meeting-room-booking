# 037 日历视图 v2 — 技术设计

## 1. 目标与约束

- 不替换 v1，独立新增 v2 路由 `/schedule/v2`。
- 视觉参考飞书日历新版（左侧任务栏 + 主视图 + 右侧详情抽屉）。
- 双 Tab：「我的日历」（当前用户视角）+「会议室日历」（管理员视角，按会议室行展示）。
- 日 / 周 / 月三种视图模式。
- 零后端改动，复用现有接口。

## 2. 布局结构

```
┌──────────────┬─────────────────────────────┬─────────────┐
│ 左侧任务栏    │ 主视图                       │ 右侧详情抽屉 │
│ 240px        │ flex:1                       │ 360px       │
│              │                             │ (点击事件滑出)│
│ - 迷你月历    │ - 顶部控制栏（导航/视图切换） │ - 事件详情  │
│ - 双 Tab 切换 │ - 日/周/月视图               │ - 参会人    │
│ - 工作时段开关│                             │ - 操作按钮  │
│ - 今日卡片    │                             │             │
└──────────────┴─────────────────────────────┴─────────────┘
```

- 左侧任务栏固定 240px，主视图 flex:1，右侧抽屉 360px（点击事件时滑入，关闭按钮/空白点击滑出）。
- 窄屏（<1280px）时左侧任务栏可折叠为图标条。

## 3. 数据流

### 3.1 「我的日历」Tab

- 调用 `listMyReservations({ page:1, size:500, startTime, endTime })`
  - 日视图：`startTime = endTime = 当天`
  - 周视图：`startTime = 周一, endTime = 周日`
  - 月视图：`startTime = 月初前最近周日, endTime = 月末后最近周六`（覆盖 6×7 网格）
- 返回数据按 `startTime` 落到对应日/格。

### 3.2 「会议室日历」Tab

- 调用 `getSchedule({ date | startDate+endDate })`（v1 同款）
- 返回 `{ rooms: [...], reservations: [...] }`
- 日视图：按会议室行展示，事件块按时间横向定位（复用 v1 的 dayEventStyle 逻辑）
- 周视图：按天列展示，事件块按时间纵向定位
- 月视图：按日格展示

### 3.3 详情抽屉

- 点击事件 → 调用 `getMyReservationDetail(id)`（普通用户）或 `getReservationDetail(id)`（管理员）
- 抽屉右侧滑入，展示：主题/时间/会议室/预约人/参会人列表/状态/备注
- 操作按钮：编辑（管理员/创建者）、取消（创建者且未开始）、删除（已取消/已拒绝）

## 4. 视觉规范

### 4.1 配色

| 元素 | 颜色 |
|------|------|
| 主色 | `#667eea`（蓝紫，复用项目主题色） |
| 待确认 | `#f59e0b`（橙） |
| 已确认 | `#10b981`（绿） |
| 已取消 | `#9ca3af`（灰） |
| 已拒绝 | `#ef4444`（红） |
| 工作时段带 | `rgba(102,126,234,0.06)` |
| 当前时间线 | `#3b82f6` |

### 4.2 事件块

- 圆角 6px
- 左侧 3px 状态色条
- 浅色填充（状态色 alpha 0.15）
- 悬停：阴影 `0 4px 12px rgba(0,0,0,0.08)` + 微上移 `-1px`
- 内容：主题（粗体 12px）+ 时间（10px 灰）+ 会议室/预约人（10px 灰）

### 4.3 控制栏

- 高度 48px，底部 1px 分隔线
- 左：[今天] [◀ ▶] [日|周|月] [日期显示]
- 右：[+ 预约] [返回 v1]

### 4.4 左侧任务栏

- 迷你月历（180px 高）：月份切换 + 7×6 网格，今日高亮，有预约的日期加圆点
- Tab 切换：`segmented control` 风格
- 「仅工作时段」开关：勾选后主视图只展示 09:00-18:00
- 「今日」卡片：显示今日预约数 + 下一场会议时间

## 5. 视图模式实现

### 5.1 日视图

「我的日历」：单行时间轴（00:00-24:00），事件块按时间纵向定位。
「会议室日历」：复用 v1 的横向多行布局（每个会议室一行，时间横向）。

### 5.2 周视图

两 Tab 统一：7 列 × 24 行网格，事件块按 (天列, 时间行) 定位。重叠事件用并查集算法分列（复用 v1 的 `weekEventLayoutMap` 逻辑）。

### 5.3 月视图

两 Tab 统一：6×7 网格，每格显示前 3 条 + 「+N 更多」。

## 6. 交互

| 操作 | 行为 |
|------|------|
| 点击事件 | 右侧抽屉滑出展示详情 |
| 点击空白时段 | 打开 BookingDialog 快速预约（预填时间） |
| 拖拽日视图横向滚动 | 复用 v1 的 pointer 拖拽逻辑 |
| 迷你月历点击日期 | 主视图跳转到该日期 |
| Tab 切换 | 重新加载数据，保持当前视图模式和日期 |
| 工作时段开关 | 切换主视图的工作时段高亮带 |

## 7. 复用 v1 逻辑

以下逻辑从 v1 复制到 v2（不抽公共函数，避免改动 v1 引入风险）：
- 时间格式化 `formatDate` / `formatTime`
- 周视图重叠布局 `weekEventLayoutMap`（并查集分列）
- 日视图事件定位 `dayEventStyle`
- 周视图事件定位 `weekEventStyle`
- 拖拽滚动 `onDayPointerDown/Move/Up` + 惯性滚动
- 当前时间线 `nowTimestamp` + 定时刷新

## 8. 风险与后续

- **大用户量性能**：「我的日历」单次查 500 条，超大用户场景可能不够；后续可加 `/my-range` 接口或虚拟滚动。
- **抽屉与移动端**：抽屉 360px 在移动端会占满屏，后续可做响应式适配。
- **v1 入口**：v1 顶部加「体验新版」按钮跳转 v2，未来 v2 稳定后可考虑替换 v1。
