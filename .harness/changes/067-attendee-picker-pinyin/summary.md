# 067-attendee-picker-pinyin

## 需求摘要

- #9 预约会议室表单「参会人员」交互优化：原「部门筛选下拉 + 全选按钮」与人员
  多选框分离，选中部门仅过滤下拉内容、并非勾选，易被误解为"已选全部门"。
  改为飞书风格弹窗式选人。
- #10 通讯录与参会人选择支持拼音检索（全拼 / 首字母）。

## 技术变更清单（均前端，后端零改动）

- `package.json`：新增依赖 `pinyin-pro`
- `src/utils/pinyinMatch.ts`（新增）：`matchUserByKeyword(user, keyword)`，
  支持姓名中文 / 全拼（zhangsan）/ 首字母（zs）/ 用户名 / 手机号 / 邮箱匹配，
  姓名拼音按字符串缓存避免重复转换
- `src/components/UserSelectDialog.vue`（新增，公共组件）：
  - 布局：顶部搜索框（拼音）+ 已选人员 chips（可单个移除/清空）；
    左侧部门树（节点带复选框，勾选部门=全选该部门含子部门人员，半选态支持）；
    右侧人员复选列表（头像/姓名/部门/联系方式）
  - 交互：搜索时跨部门全量匹配；点击树节点按部门范围筛选；
    「确定」才回传父组件（取消不生效）
- `src/components/BookingDialog.vue`：
  - 移除部门筛选工具栏 + el-select 多选、部门树加载与分组过滤逻辑
  - 参会人员区改为 chips 展示（可单个移除）+ 点击打开 UserSelectDialog
- `src/views/contacts/ContactsView.vue`：搜索过滤接入 `matchUserByKeyword`

## 交互语义修复点（#9 根因）

- 旧：选部门 = 过滤视图（无勾选），全选按钮在旁易被忽略
- 新：勾选部门节点 = 立即选中该部门（含子部门）全部人员，
  半选/全选状态实时可见，无歧义

## 验证

- `npm run build`（vue-tsc 类型检查 + vite build）通过
- pinyin-pro 词典自动拆分独立 chunk（~142KB gzip），仅按需加载，不影响首屏

## 手工验证点

1. 预约表单 → 点击参会人员区 → 弹窗：勾选部门节点，右侧该部门人员全选中，
   已选区出现对应人员；部分勾选时部门呈半选态
2. 弹窗搜索框输入 `zs` / `zhangsan` 均能命中「张三」；取消后已选不变更，确定后回显
3. 通讯录页搜索框输入拼音/首字母可过滤；原中文/手机号/邮箱搜索不受影响
