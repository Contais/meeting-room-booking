# 070 前端 UI/UX 规范沉淀

## 需求摘要

前端审美与交互优化工作告一段落，将期间沉淀的页面视觉、交互、组件、表单、头像、列表与图表规范整理进 `.harness` 规则文档，供后续前端任务统一遵循。

## 技术变更清单

- 新增 `.harness/rules/前端UI规范.md`：
  - 设计 Token（品牌主色、文字层级、圆角、深色模式）
  - 表单规范（`.form-standard`、必填红星、选填标签、输入宽度）
  - 头像规范（`UserAvatar`、中性底色、无描边、容器裁切）
  - 详情页标题规范（页面类型标题，避免与字段重复）
  - 列表页规范（序号、空状态、操作列「更多」下拉、列宽统一）
  - 交互与无障碍（键盘可达、拖拽替代、错误就近、reduced-motion）
  - 图表规范（固定卡片高度、小角度旋转 + 省略 + tooltip）
  - 组件复用清单（`UserSelectDialog` / `FormDrawer` / `FileUpload` / `UserAvatar` 等）
- `AGENTS.md`：规则索引表与阶段 1 知识加载表登记新规范文件。
- `.harness/rules/代码规范.md`：前端章节补充 §3.5 UI / 交互规范指引。

## 冲突与风险

- 仅文档变更，不改变任何运行逻辑。
- 规范为建议性约束；后续前端 UI 任务需先读取该文档再编码。
