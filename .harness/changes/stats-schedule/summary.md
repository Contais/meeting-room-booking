# 数据统计 + 日程视图 - 需求分析

## 功能一：数据统计

### 需求描述
管理员可在首页或统计页面查看会议室使用情况的可视化数据。

### 验收标准
| 编号 | 验收条件 |
|------|----------|
| AC-1 | 今日预约数、本周预约数、总预约数统计卡片 |
| AC-2 | 待审批预约数统计卡片 |
| AC-3 | 会议室使用率柱状图（按会议室展示今日/本周使用时长占比） |
| AC-4 | 高峰时段分布图（按时段展示预约数量） |

### 技术变更
| 变更项 | 文件 | 说明 |
|--------|------|------|
| HomeController | 修改 | 新增统计接口 |
| HomeView.vue | 修改 | 首页增加统计图表 |

## 功能二：日程视图

### 需求描述
用户可按日/周查看所有会议室的预约日程，类似 Google Calendar 的时间轴视图。

### 验收标准
| 编号 | 验收条件 |
|------|----------|
| AC-1 | 日视图：纵轴为时间（8:00-20:00），横轴为会议室，预约以色块展示 |
| AC-2 | 周视图：切换到按周查看，每天一列 |
| AC-3 | 可前后切换日期/周 |
| AC-4 | 点击预约色块可查看详情 |
| AC-5 | 已登录用户可从日程视图直接跳转预约 |

### 技术变更
| 变更项 | 文件 | 说明 |
|--------|------|------|
| ReservationController | 修改 | 新增日程查询接口 |
| ScheduleView.vue | 新建 | 日程视图页面 |
| router/index.ts | 修改 | 添加日程视图路由 |
| MainLayout.vue | 修改 | 添加菜单项（通过菜单管理） |

## 涉及模块
- mrb-meeting（后端统计 + 日程查询）
- frontend（首页图表 + 日程视图页面）
