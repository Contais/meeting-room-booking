# 前端 UI / UX 规范

> 适用范围：所有前端页面、组件、视觉与交互调整。涉及前端 UI 的任务必须先读本文档。
> 本文档沉淀自多轮 UI/UX 审美优化、无障碍改造与交互统一工作，是「预约会议室」等页面的统一标准。

## 1. 设计 Token（样式变量）

- 品牌主色：`--primary: #4f6ef7`（靛蓝）；品牌渐变 `#667eea → #764ba2`（`--primary-gradient`）。
- 文字层级：`--text-primary`（标题/正文）、`--text-secondary`（次要）、`--text-muted`（弱化/提示）。
- 背景与边框：`--bg-page`、`--bg-card`、`--border`、`--border-light`；圆角统一 `--radius: 12px`。
- **新代码禁止硬编码品牌色 / 文字色**，一律使用上述 token；深色模式由 token 自动适配（见 `frontend/src/styles/global.css`）。
- 全局交互反馈：`:focus-visible` 使用 `2px solid var(--primary)` 描边，不得移除或覆盖为不可见。

## 2. 表单规范

- 弹窗 / 抽屉内表单统一 `label-position="top"`，并添加 `.form-standard` 类（全局样式，统一标签字号、间距、内容对齐）。
- 标签样式：13px / 500 字重 / `var(--text-primary)`；表单项间距 16px。
- 必填项：在 `rules` 中声明 `required: true`（或 `el-form-item` 加 `required`），自动显示红色 `*`，禁止省略标记。
- 选填项：「（选填）」放在**标签**上，不放在占位符里；占位符只写动作提示（如「请输入会议主题」）。
- 输入宽度：普通输入 / 选择器 100%；紧凑数字控件（时长、排序等）用 `width:180px` 并附单位文字（分钟 / 天）。

## 3. 头像规范

- 统一使用 `UserAvatar` 组件（图片 URL / 图标 JSON / 首字母三态），禁止各页面另写一套头像实现。
- 容器：`border-radius: 50%` + `overflow: hidden`；图片 `width/height:100%; object-fit: cover`，**图片自身不加 border-radius**，由容器裁切，避免边缘露底。
- 图片头像底色使用中性色 `var(--bg-page)`，禁止在图片下方透出品牌渐变（会形成「紫色圆」）。
- 头像容器不加 `border` / `box-shadow` 描边；编辑角标避免紫色填充圈。
- 头像上传使用 `FileUpload shape="avatar"`（圆形、无虚线边框）。

## 4. 详情页规范

- 标题使用**页面类型**（预约详情 / 会议室详情 / 用户详情 / 设备详情），不展示实体名 / 会议主题，避免与正文字段重复。
- 实体名称 / 主题在正文头部块或字段中展示一次；多入口复用同一详情页时可用路由 `dt` 参数区分标题（如预约详情 / 会议详情）。

## 5. 列表页规范

- 序号列：`type="index"` + `(page-1)*size+index`，width 70 居中，使用全局统一编号。
- 空状态：`empty-text` 给出引导文案，不显示空白表格。
- 操作列：常用操作直接展示（详情 / 编辑 / 删除），低频操作收进「更多」下拉（`.action-links` + 全局 `.action-menu-popper`）；危险操作用红色并放入下拉。
- 操作列宽度按页面统一：用户 / 设备 180、角色 200、预约 170、会议室 180、部门 / 菜单 220；不得挤压内容列。
- 文本列用 `min-width`，状态 / 人数 / 时间等定宽居中。

## 6. 交互与无障碍

- 可点击区域支持键盘：`role="button"` / `tabindex` / Enter / Space（或直接使用 `el-button`）。
- 拖拽交互必须提供点选替代（如时间轴：点击起点 → 点击终点），并支持键盘方向键；触屏滚动不得卡住拖拽状态。
- 表单错误就近显示在字段下方；提交按钮在异步期间 loading 并禁用。
- 动效遵循 `prefers-reduced-motion`。
- 图标按钮需可访问名称；装饰性图标 `aria-hidden`。

## 7. 图表规范（ECharts）

- 图表卡片高度固定 260px，多图并排时保持一致，不因数据量撑高卡片。
- 类别多时的标签处理优先级：**小角度旋转（30°）+ 省略 + tooltip 显示全名**；禁止竖排 / 旋转 90°（会压缩图表或撑高卡片）。
- 类别 ≤ 6 横排；> 6 旋转 30°；名称 > 6 字省略（tooltip 全名）。
- 比较类图表按值降序；百分比柱状图可在条形末端直接标注数值。
- 类别 20+ 建议改为横向条形图或表格。

## 8. 组件复用

- 选人：统一使用 `UserSelectDialog`（左部门树 + 右人员列表 + 拼音搜索）；需要「已选 / 已邀请不可重复选」时传 `lockedUsers`（置灰 + 状态标签），勾选部门会自动跳过锁定人员。
- 弹窗表单：`FormDrawer`；图片上传：`FileUpload`；头像：`UserAvatar`；列表容器：`TableCard`；筛选：`SearchBar`。
- 新增页面优先复用上述组件，禁止另起一套相似实现。
