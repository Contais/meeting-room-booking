# 领域术语 (Domain Glossary)

## 1. 核心业务术语

| 术语 | 英文/缩写 | 定义 | 代码体现 |
|------|-----------|------|----------|
| 会议室 | Meeting Room | 可预约的实体会议室，含位置、容量、设备设施与使用规则。 | `MeetingRoom` 实体 / `MeetingRoomVO` |
| 预约 | Reservation | 用户对某会议室某时段的预约单，状态机见 §2.2。 | `MeetingRoomReservation` 实体 / `ReservationVO` |
| 预约编号 | Reservation Code | 预约业务编号，格式 B + yyyyMMdd + 6 位序列，全局唯一。 | `reservationCode` 字段 |
| 参会人 | Attendee | 被邀请参加预约的用户，有独立的响应状态。 | `ReservationAttendee` 实体 / `AttendeeVO` |
| 部门 | Department | 组织树节点，用于通讯录与按部门邀请参会人。 | `Department` 实体 / `DepartmentVO` |
| 菜单 | Menu | 前端导航菜单项，按角色分配可见性。 | `Menu` 实体 / `MenuVO` |
| 角色 | Role | 权限角色，当前仅 ROLE_ADMIN / ROLE_USER。 | `RoleEnum` / `Role` 实体 |
| 设备 | Equipment | 会议室设施（投影仪、白板等），与会议室多对多关联。 | `Equipment` / `RoomEquipment` 实体 |
| 通知 | Notification | 站内信，按用户投递（预约创建/审批/拒绝等事件触发）。 | `Notification` 实体 / `NotificationVO` |
| 字典 | Dict | 枚举型展示数据（预留扩展）。 | `SysDict` / `SysDictItem` 实体 |
| 系统配置 | SysConfig | 可动态调整的键值对运营参数。 | `SysConfig` 实体 |
| 审批模式 | Approval Mode | 会议室是否需管理员审批。 | `ApprovalModeEnum` |
| 幂等性 | Idempotency | 同一操作重复执行结果一致；MQ 消费者必须幂等（Redis 防重）。 | RocketMQ Consumer |
| 预签名 URL | Presigned URL | COS 私有桶按需生成的临时访问链接。 | `FileInternalController` |

## 2. 状态定义

### 2.1 启用状态（EnableStatusEnum）
- **DISABLED (0)**：禁用。会议室/设备/用户/部门等不可用。
- **ENABLED (1)**：启用。

### 2.2 预约状态（ReservationStatusEnum）
- **PENDING (0)**：待确认。预约已创建，等待管理员审批。
- **CONFIRMED (1)**：已确认。预约生效，用户可使用。
- **CANCELLED (2)**：已取消。用户主动取消预约。
- **REJECTED (3)**：已拒绝。管理员拒绝，可附带拒绝原因（`reject_reason`）。
- 时段可用性：`CANCELLED` 与 `REJECTED` 视为时段已释放（`ReservationStatusEnum.EXCLUDED_CODES`）。

### 2.3 参会人状态（AttendeeStatusEnum）
- **PENDING (0)**：待查阅（待响应）。
- **ACCEPTED (1)**：已接受。
- **DECLINED (2)**：已拒绝。

### 2.4 其他状态
- **审批模式（ApprovalModeEnum）**：FREE_APPROVAL (0) 免审批 / NEED_APPROVAL (1) 需审批。
- **菜单可见性（VisibleEnum）**：HIDDEN (0) 隐藏 / VISIBLE (1) 显示。
- **逻辑删除（deleted）**：0-未删除 / 1-已删除（`@TableLogic` + `DeletedEnum`）。
- **用户角色（RoleEnum）**：ROLE_ADMIN 超级管理员 / ROLE_USER 普通用户。
- **通知已读（is_read）**：0-未读 / 1-已读。

## 3. 技术术语

| 术语 | 解释 | 代码/配置示例 |
|------|------|----------------|
| Entity | 数据库实体，继承 `BaseEntity`。 | `MeetingRoom`, `User` |
| DTO | Data Transfer Object，入参对象。 | `ReservationCreateDTO`, `UserCreateDTO` |
| VO | View Object，出参对象。 | `ReservationVO`, `UserVO` |
| BaseEntity | 实体基类：id（雪花主键）+ createTime/updateTime（自动填充）+ deleted（逻辑删除）。 | `com.meetinghub.common.model.BaseEntity` |
| 雪花 ID | MyBatis-Plus 内置雪花算法生成的 Long 主键。 | `@TableId(type = IdType.ASSIGN_ID)` |
| 统一响应 | 所有接口返回 `{code, message, data}`。 | `Result<T>` |
| 业务异常 | 业务错误统一抛 `BusinessException` + `ErrorCode`，禁止裸抛 RuntimeException。 | `ErrorCode` |
| JWT | 登录令牌；网关验签并校验 Redis 一致性，向下游注入 X-User-* 头。 | `Authorization: Bearer <token>` |
| Redis Key | 缓存键统一前缀 `mrb:`。 | `RedisKeyConstant` |
| SSE | Server-Sent Events，AI 对话流式逐块返回。 | `ChatController#chatStream` |

## 4. 命名约定 (Naming Conventions)
1. **实体/表**：实体类大驼峰（`MeetingRoom`）；表名 snake_case（`meeting_room`）；字段实体 camelCase、数据库 snake_case。
2. **布尔值**：`is` 或 `has` 前缀（如 `isRead`, `isSystem`）。
3. **时间字段**：`Time` 后缀（如 `createTime`, `startTime`）。
4. **ID**：`Id` 后缀（如 `roomId`, `departmentId`）。
5. **金额字段**：若新增金额，必须使用 `BigDecimal`（元为单位，保留两位小数），禁止 `{attribute}Cents` 命名（编码红线 1）。
6. **常量**：全大写 + 下划线，限定名引用，禁止 `import static`。
7. **状态字段**：使用对应枚举（EnableStatusEnum / ReservationStatusEnum 等），禁止魔法数字。
