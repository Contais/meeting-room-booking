# 接口协议 (API Protocol)

## 1. 总览

### 1.1 网关路由
所有请求经 Spring Cloud Gateway（mrb-gateway，端口 8080）统一路由，外部访问路径均带 `/api` 前缀：

| 外部路径前缀 | 目标服务 | 说明 |
|--------------|----------|------|
| `/api/uc/**` | mrb-user | 用户、部门、菜单、角色 |
| `/api/auth/**` | mrb-auth | 登录、刷新、登出 |
| `/api/meeting/**` | mrb-meeting | 会议室、预约、设备、首页统计、AI 助手 |
| `/api/platform/**` | mrb-platform | 通知、字典、系统配置、文件 |
| `/ws/**` | mrb-platform | WebSocket 通知推送（token 走 query 参数） |

### 1.2 认证方式
- 请求头携带 `Authorization: Bearer {JWT}`。
- 网关验签 + Redis 一致性校验通过后，向下游服务注入 `X-User-Id`、`X-User-Role`、`X-User-Username` 头。
- 匿名白名单（不校验 Token）：`/api/auth/login`、`/api/uc/user/register`、本地存储静态资源前缀。

### 1.3 通用约定
- 时间格式：`yyyy-MM-dd HH:mm:ss`（LocalDateTime 统一序列化）。
- 主键 `Long` 统一序列化为字符串，避免前端精度丢失。
- 分页入参：`page`（默认 1）、`size`（默认 10）；分页响应为 MyBatis-Plus `IPage<T>`：`records / total / size / current / pages`。
- 业务成功与否以响应体 `code` 为准；HTTP 状态码除网关 401 外通常为 200。

### 1.4 路径与 Controller 映射约定
- 网关 `StripPrefix` 决定服务实际收到的路径：`StripPrefix=1`（`/api/auth`、`/api/meeting`、`/api/platform`）只剥掉 `/api`，Controller 必须自带服务前缀（`/auth`、`/meeting/...`、`/platform/...`）；`StripPrefix=2`（`/api/uc/**`）剥掉 `/api/uc`，Controller 直接映射子资源（`/user`、`/department`）。
- Controller 统一使用类级 `@RequestMapping` 声明前缀，方法只写子路径。
- 服务间 Feign 内部接口统一放在 `/platform/internal/<resource>/**`（internal 在前），并拆分为独立 Controller（如 `NotificationInternalController`），与公共接口分离。
- 禁止用 `server.servlet.context-path` 承载服务前缀：会连带影响 WebSocket（`/ws/**`）、Feign 内部路径与静态资源，导致双前缀或路径搬家。

## 2. 通用响应格式

所有业务接口统一返回 `{code, message, data}`：

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 业务码：200 成功，非 200 失败 |
| message | String | 提示信息 |
| data | T | 业务数据，可为 null |

### 2.1 HTTP 状态码
| 状态码 | 说明 |
|--------|------|
| 200 | 请求处理完成（业务成败见 body.code） |
| 401 | 未授权 / Token 无效（网关拦截，统一 JSON） |
| 500 | 服务器内部错误 |

### 2.2 业务错误码（ErrorCode）
| 响应码 | 说明 |
|--------|------|
| 200 | 操作成功 |
| 400 | 参数错误（含 @Valid 校验失败） |
| 401 | 未授权 |
| 403 | 禁止访问（@RequiresRole 权限不足） |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
| 1001 | 会议室不存在 |
| 1002 | 会议室已禁用 |
| 1003 | 时段已被预约 |
| 1004 | 预约记录不存在 |
| 1005 | 用户不存在 |
| 1006 | 用户已存在 |
| 1007 | Token 无效或已过期 |
| 1008 | Token 已过期 |
| 1009 | 用户名格式不正确（2-32 位字母数字下划线） |
| 1010 | 手机号格式不正确 |
| 1011 | 手机号已注册 |
| 1012 | 部门不存在 |
| 1013 | 部门名称已存在 |
| 1014 | 存在子部门，不允许删除 |
| 1015 | 部门下有用户，不允许删除 |
| 1016 | 不能将部门移动到其子部门下 |
| 1017 | 菜单不存在 |
| 1018 | 存在子菜单，不允许删除 |
| 1019 | 设备不存在 |
| 1020 | 设备编码已存在 |
| 1021 | 该用户未被邀请 |
| 1022 | 该用户已被邀请 |
| 1023 | 无权操作他人预约 |
| 1101 | 上传文件不能为空 |
| 1102 | 上传文件超过大小限制 |
| 1103 | 不支持的文件类型 |
| 1104 | 无效的业务类型 |
| 1105 | 文件上传失败 |
| 1106 | 文件不存在 |

## 5. 错误处理约定
- 参数校验失败：body.code = 400，message 含字段级错误明细。
- 业务失败：body.code 取 ErrorCode 业务码（如 1003 时段已被预约），message 为业务提示。
- 未登录 / Token 无效：网关直接返回 HTTP 401，body 为 `{"code":401,"message":"未授权或Token无效","data":null}`。
- 权限不足：body.code = 403，message 提示所需角色。
