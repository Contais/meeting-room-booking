# 数据模型 (Data Model)

## 1. 数据库统一规范（强制）

### 1.1 基础字段
所有业务表必须包含以下四个基础字段：

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | 主键，NOT NULL | 主键，Java 类型 `Long`，MyBatis-Plus 雪花算法生成 |
| create_time | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |
| deleted | TINYINT | NOT NULL DEFAULT 0 | 逻辑删除：0-未删除，1-已删除 |

### 1.2 主键策略
- 统一使用 `Long` 类型 + MyBatis-Plus 内置雪花算法：`@TableId(type = IdType.ASSIGN_ID)`。
- 禁止使用数据库自增主键（`AUTO_INCREMENT` / `IdType.AUTO`）。

### 1.3 实体映射
- 公共基础字段可抽取父类 `BaseEntity`（建议置于 mrb-common 模块），各业务实体继承。
- `create_time` / `update_time` 使用 MyBatis-Plus 字段自动填充，`deleted` 使用 `@TableLogic` 逻辑删除。

## 2. 数据库表结构

### 2.1 会议室表 (meeting_rooms)

| 字段名 | 类型 | 注释 |
|--------|------|------|
| id | BIGINT | 主键 |
| name | VARCHAR(64) | 会议室名称 |
| status | TINYINT | 状态: 0-禁用, 1-启用 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |
| deleted | TINYINT | 是否删除: 0-否, 1-是 |


### 2.2 会议室预约表 (meeting_room_reservations)

| 字段名 | 类型 | 注释 |
|--------|------|------|
| id | BIGINT | 主键 |
| room_id | BIGINT | 会议室ID |
| start_time | DATETIME | 开始时间 |
| end_time | DATETIME | 结束时间 |
| status | TINYINT | 状态: 0-待确认, 1-已确认, 2-已取消 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |
| deleted | TINYINT | 是否删除: 0-否, 1-是 |
