# 数据模型 (Data Model)

## 1. 数据库统一规范（强制）

### 1.1 基础字段
所有业务表必须包含以下四个基础字段：

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | 主键，NOT NULL | 主键，Java 类型 `Long`，MyBatis-Plus 雪花算法生成 |
| create_time | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |
| deleted | TINYINT | NOT NULL DEFAULT 0 | 逻辑删除：0-未删除，1-已删除 |

### 1.2 主键策略
- 统一使用 `Long` 类型 + MyBatis-Plus 内置雪花算法：`@TableId(type = IdType.ASSIGN_ID)`。
- 禁止使用数据库自增主键（`AUTO_INCREMENT` / `IdType.AUTO`）。

### 1.3 实体映射
- 公共基础字段可抽取父类 `BaseEntity`（建议置于 mrb-common 模块），各业务实体继承。
- `create_time` / `update_time` 使用 MyBatis-Plus 字段自动填充，`deleted` 使用 `@TableLogic` 逻辑删除。

## 2. 数据库（按库）

基础字段（id / create_time / update_time / deleted）见 §1，以下各表不再重复展开，仅在“索引/约束”与业务字段中体现。

### 2.1 mrb_user 用户中心

#### user 用户表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| username | VARCHAR(64) | NOT NULL，用户名 |
| password | VARCHAR(128) | NOT NULL，BCrypt 哈希 |
| phone | VARCHAR(20) | 手机号，空串归一化为 NULL |
| email | VARCHAR(128) | 邮箱 |
| avatar | VARCHAR(512) | 头像 objectKey |
| real_name | VARCHAR(64) | 真实姓名 |
| department_id | BIGINT | 所属部门ID |
| role | VARCHAR(20) | NOT NULL DEFAULT 'ROLE_USER'：ROLE_ADMIN / ROLE_USER |
| status | TINYINT | NOT NULL DEFAULT 1：0-禁用, 1-启用 |

索引/约束：UNIQUE `uk_phone_active` (phone, deleted)

#### department 部门表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| name | VARCHAR(64) | NOT NULL，部门名称 |
| parent_id | BIGINT | DEFAULT 0，父部门ID，0 为顶级 |
| sort_order | INT | DEFAULT 0，排序号 |
| status | TINYINT | NOT NULL DEFAULT 1：0-禁用, 1-启用 |

索引/约束：KEY idx_parent_id (parent_id)

#### menu 菜单表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| name | VARCHAR(64) | NOT NULL，菜单名称 |
| path | VARCHAR(128) | 路由路径 |
| icon | VARCHAR(64) | 图标名称 |
| parent_id | BIGINT | DEFAULT 0，父菜单ID |
| sort_order | INT | DEFAULT 0，排序号 |
| visible | TINYINT | NOT NULL DEFAULT 1：0-隐藏, 1-显示 |
| status | TINYINT | NOT NULL DEFAULT 1：0-禁用, 1-启用 |

索引/约束：KEY idx_parent_id (parent_id)

#### role 角色表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| role_code | VARCHAR(50) | NOT NULL，角色编码 |
| role_name | VARCHAR(100) | NOT NULL，角色名称 |
| description | VARCHAR(500) | 角色描述 |
| status | TINYINT | NOT NULL DEFAULT 1：0-禁用, 1-启用 |
| is_system | TINYINT | NOT NULL DEFAULT 0：1-系统角色 |
| sort | INT | NOT NULL DEFAULT 0，排序 |

索引/约束：UNIQUE `uk_role_code` (role_code, deleted)

#### role_menu 角色菜单关联表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| role | VARCHAR(20) | NOT NULL，角色编码 |
| menu_id | BIGINT | NOT NULL，菜单ID |

索引/约束：UNIQUE `uk_role_menu` (role, menu_id)；KEY idx_menu_id (menu_id)

#### notification 通知表（旧，已迁至 mrb_platform，可清理）
结构与 mrb_platform.notification 一致，见 §2.4。

### 2.2 mrb_meeting 会议室中心

#### meeting_room 会议室表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| name | VARCHAR(64) | NOT NULL，会议室名称 |
| location | VARCHAR(128) | 位置（楼层/房间号） |
| capacity | INT | 容纳人数 |
| equipment | VARCHAR(256) | 设备设施（冗余展示用） |
| image_url | VARCHAR(512) | 实景图片 objectKey |
| description | TEXT | 描述 |
| status | TINYINT | NOT NULL DEFAULT 1：0-禁用, 1-启用 |
| bookable_start | VARCHAR(5) | DEFAULT '08:00'，可预约开始时间 |
| bookable_end | VARCHAR(5) | DEFAULT '20:00'，可预约结束时间 |
| max_duration | INT | DEFAULT 480，单次最大预约时长（分钟） |
| advance_days | INT | DEFAULT 7，提前预约天数限制 |
| need_approval | TINYINT | DEFAULT 0：0-免审批, 1-需审批 |

索引/约束：无唯一索引

#### meeting_room_reservation 会议室预约表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| reservation_code | VARCHAR(20) | 预约编号：B + yyyyMMdd + 6 位序列 |
| room_id | BIGINT | NOT NULL，会议室ID |
| user_id | BIGINT | NOT NULL，预约用户ID |
| subject | VARCHAR(128) | 会议主题 |
| attendee_count | INT | 参会人数（由参会人列表派生） |
| contact_phone | VARCHAR(20) | 联系人手机号（历史字段，实体未映射） |
| remark | VARCHAR(512) | 备注 |
| start_time | DATETIME | NOT NULL，开始时间 |
| end_time | DATETIME | NOT NULL，结束时间 |
| status | TINYINT | NOT NULL DEFAULT 0：0-待确认, 1-已确认, 2-已取消, 3-已拒绝 |
| reject_reason | VARCHAR(255) | 拒绝原因（status=3 时填充） |

索引/约束：UNIQUE `uk_reservation_code` (reservation_code)；KEY idx_room_id；KEY idx_user_id；KEY idx_time_range (start_time, end_time)

#### equipment 设备表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| code | VARCHAR(50) | NOT NULL，设备编码 |
| name | VARCHAR(100) | NOT NULL，设备名称 |
| category | VARCHAR(50) | 设备分类 |
| brand | VARCHAR(64) | 品牌 |
| model | VARCHAR(100) | 型号 |
| status | TINYINT | NOT NULL DEFAULT 1：0-禁用, 1-启用 |
| purchase_date | DATE | 购置日期 |
| description | VARCHAR(500) | 设备描述 |

索引/约束：UNIQUE `uk_equipment_code` (code, deleted)；KEY idx_category；KEY idx_status

#### room_equipment 会议室-设备关联表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| room_id | BIGINT | NOT NULL，会议室ID |
| equipment_id | BIGINT | NOT NULL，设备ID |
| quantity | INT | NOT NULL DEFAULT 1，数量 |

索引/约束：UNIQUE `uk_room_equipment` (room_id, equipment_id, deleted)；KEY idx_equipment_id

#### reservation_attendee 预约参会人表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| reservation_id | BIGINT | NOT NULL，预约ID |
| user_id | BIGINT | NOT NULL，参会人用户ID |
| status | TINYINT | NOT NULL DEFAULT 0：0-待查阅, 1-已接受, 2-已拒绝 |

索引/约束：UNIQUE `uk_reservation_attendee` (reservation_id, user_id, deleted)；KEY idx_user_id

### 2.4 mrb_platform 平台中心

#### notification 通知表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| user_id | BIGINT | NOT NULL，接收人ID |
| type | VARCHAR(32) | NOT NULL：RESERVATION_CREATED/APPROVED/REJECTED/CANCELLED/SYSTEM |
| title | VARCHAR(128) | 标题 |
| content | TEXT | 内容 |
| ref_type | VARCHAR(32) | 关联业务类型（reservation/user） |
| ref_id | BIGINT | 关联业务ID |
| is_read | TINYINT | NOT NULL DEFAULT 0：0-未读, 1-已读 |

索引/约束：KEY idx_user_id；KEY idx_user_read (user_id, is_read)；KEY idx_create_time

#### sys_dict 字典表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|
| code | VARCHAR(64) | NOT NULL，字典编码（唯一） |
| name | VARCHAR(64) | NOT NULL，字典名称 |
| description | VARCHAR(255) | 描述 |
| status | TINYINT | NOT NULL DEFAULT 1：0-禁用, 1-启用 |

#### sys_dict_item 字典项表
| 字段名 | 类型 | 约束/注释 |
|--------|------|-----------|

索引/约束：KEY idx_dict_id (dict_id, status, sort)

#### sys_config 系统配置表
| 字段名 | 类型 | 约束/注释 |
